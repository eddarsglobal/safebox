# SafeBox v0.2.6 — iOS Files Foundation R31

Status: **implementation checkpoint — runtime proof required on macOS/iPhone Simulator**.

Implemented: iOS `UIDocumentPicker` mode, `fileAccessMode: scoped`, Rust-side private staging before crypto, explicit security-scope release, mobile Save with byte verification, `.sbx` Open-In URL preservation, Apple custom `.sbx` exported type, `TAURI_DEV_HOST`, plus `ios:doctor` and `ios:cold-dev` tooling.

Security invariants: no crypto/SBX format change; external Files documents are never fed directly to path-based crypto; private staging remains exclusive/private; external documents are not burned; exports remain restricted to files generated by the current SafeBox session.

Compatibility note: the iOS picker deliberately does not apply a custom `.sbx` filter because the upstream custom-extension/provider selection issue is still open. SafeBox forces document mode and validates `.sbx` after selection instead.

Gate still required: real iPhone Simulator flow Files picker → Create → Save → Open-In `.sbx` → wrong code → correct code → Save original → byte identity.
